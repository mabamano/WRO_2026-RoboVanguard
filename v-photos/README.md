# Vehicle Photos (`v-photos/`)

This directory contains six high-resolution perspective photographs of the **ROBOVANGUARD** autonomous vehicle, displaying the mechanical construction, Raspberry Pi 5 camera placement, ESP32 controller, and sensor array.

---

## 📸 Image Inventory

1. `top_view.jpg` → Top perspective showing Raspberry Pi 5, ESP32 RoboGuard unit, power distribution, and battery placement.
2. `bottom_view.jpg` → Underside view of the 4 mm laser-cut acrylic chassis, motor mounting, and ground clearance (0.8 cm).
3. `front_view.jpg` → Front view illustrating Ackermann steering linkages, MG995 servo motor, Pi Camera, and 3 front ultrasonic sensors.
4. `back_view.jpg` → Rear view showing dual-shaft BO DC motor, rear ultrasonic sensor, and drive wheels.
5. `left_view.jpg` → Left side elevation showing left side ultrasonic sensor, wheel base (280 mm length), and height profile (250 mm).
6. `right_view.jpg` → Right side elevation showing right side ultrasonic sensor, TCS34725 color sensor mount, and wiring harnesses.
