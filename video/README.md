## 🚗 Performance Demonstration Features

1. **Open Track Run (Round 1):** Continuous lane keeping, black wall distance tracking, corner steering, direction indicator recognition (orange/blue), and 3 complete laps.
2. **Obstacle Avoidance & Parking Run (Round 2):** Red obstacle box (right turn) and green obstacle box (left turn) avoidance, followed by automated parking into the designated parking lot upon lap 3 completion.
