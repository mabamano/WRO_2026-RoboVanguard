# 3D Mechanical Models (`models/`)

This directory contains 3D printable mechanical components and structural brackets engineered for the **ROBOVANGUARD** vehicle.

---

## 🛠️ Parts Inventory (STL Models)

A total of 11 SLA 3D printed components were designed and fabricated for the vehicle:

1. **`ultrasonic_front_mount.stl`** → Tri-sensor mounting bracket for front ultrasonic sensors.
2. **`ultrasonic_side_mounts.stl`** → Side brackets for left and right ultrasonic lane sensors.
3. **`ultrasonic_rear_mount.stl`** → Rear bracket for distance and parking safety sensor.
4. **`bo_motor_rear_bracket.stl`** → Secure mounting bracket for the dual-shaft BO DC motor.
5. **`steering_pivot_bushes.stl`** → Precision bushings for Ackermann steering pivot joints.
6. **`steering_linkage_arm.stl`** → Mechanical linkage arms connecting MG995 servo horn to front wheel uprights.
7. **`start_button_housing.stl`** → Protective housing mount for the autonomous start button.
8. **`camera_tilt_mount.stl`** → Adjustable angle mount securing the Pi Camera module to the front of the vehicle.

---

## ⚙️ 3D Printing Parameters

* **Material:** PLA / SLA Resin
* **Infill:** 40% - 60% (Triangular / Gyroid infill for structural durability)
* **Layer Height:** 0.2 mm
* **Shell Count:** 3 perimeters
* **Support:** Enabled for overhanging linkage mounting holes
